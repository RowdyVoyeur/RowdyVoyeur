# About me

Hi, I'm Ricardo! I enjoy understanding how things work, documenting what I learn and using technology to solve practical problems. Most of my personal projects are focused on electronic music workflows, Raspberry Pi, MIDI, audio routing and making small devices do useful things.

# Current focus

- Portable Raspberry Pi audio and MIDI setups
- Patchbox OS, Pisound, JACK audio routing and embedded Linux
- Roland MC-101 and M8 Headless workflows
- Korg nanoKONTROL control mappings and performance tools

# Featured project

My Raspberry Pi-based M8 Headless [build](https://github.com/RowdyVoyeur/m8c-rpi4) was featured by Tom’s Hardware:

- [Raspberry Pi Powers DIY Headless M8 Synthesizer](https://www.tomshardware.com/news/raspberry-pi-headless-m8-synthesizer)
- [Watch the project video on YouTube](https://www.youtube.com/watch?v=DSROTH714Ns)

That project started as a portable M8 Headless setup and later inspired more advanced experiments with audio routing, MIDI control and integration with the Roland MC-101.

# Projects worth checking

- [m8c-rpi4](https://github.com/RowdyVoyeur/m8c-rpi4)  
  A Raspberry Pi-focused M8C setup for running M8 Headless in a compact, portable device built entirely out of Lego.

- [mc101-pisound](https://github.com/RowdyVoyeur/mc101-pisound)  
  A portable Raspberry Pi 4, Patchbox OS and Blokas Pisound setup that adds audio input, routing, HUD feedback and extended control to the Roland MC-101.
